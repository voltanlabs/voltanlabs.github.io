# Archived Data Discovery shell

The former `databyte-discovery.html` runtime was retired as the primary game entry point on 2026-08-12.

The active game is now [`/three-battle/`](../../three-battle/), which owns the current standalone Three.js Data Discovery runtime, save namespace, battle loop, progression, capture, regions, Dex, and presentation.

The redirect at the former URL is intentional so existing bookmarks continue into the current game. The legacy runtime remains recoverable from Git history by restoring `databyte-discovery.html` from the commit immediately before the cutover.
